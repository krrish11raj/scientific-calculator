# Scientific Calculator

A fully functional scientific calculator built with HTML, CSS, and JavaScript.

## Features
- Basic arithmetic operations (+, -, ×, ÷)
- Scientific functions (sin, cos, tan, log, ln, √, x²)
- Mathematical constant (π)
- Calculation history
- Responsive design

## Technologies Used
- HTML5
- CSS3
- JavaScript (ES6)
